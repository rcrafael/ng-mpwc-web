## Prerequisites
- Use Sweetalert2 library to create and replace `Alert` and `Confirm` dialog box
- Only use one standard design/style for all Sweetalert
- For existing native `confirm` and `alert` dialog box, use the original text provided.

## Confirm Dialog
- `Confirm`, `Yes`, `Ok`, `Proceed` button should be on the left side of the dialog box
- `Cancel`, `No` button should be on the right side of the dialog box
- Generate appropriate, short title for each of the confirm dialog box

## Alert Dialog
- Title is not necessary, show the message straight forward to the users
